# ITMO Calendar Sync

Небольшой сервис на Rust, который получает личное расписание из `my.itmo.ru` и публикует его как приватную iCalendar-подписку для Apple Calendar.

## Как это работает

```text
my.itmo.ru → Rust-сервис → nginx-proxy → постоянный HTTPS URL .ics
                                      ↓
                                Apple Calendar

ошибка обновления → Telegram Bot API через VLESS + Reality
восстановление     → одно зелёное сообщение в Telegram
```

Сервис хранит последнее успешно полученное расписание в памяти. Если ИТМО временно недоступен, он продолжает отдавать старую рабочую версию. При первой ошибке отправляется одно уведомление; повторяющиеся ошибки подавляются. После восстановления приходит одно сообщение.
