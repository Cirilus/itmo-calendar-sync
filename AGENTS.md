# AGENTS.md

Этот каталог содержит отдельный сервис синхронизации расписания ИТМО с календарями по подписке iCalendar.

Сервис написан на Rust и разворачивается через Docker Compose. Изменения должны оставаться небольшими и проверяемыми. Секреты, учётные данные ИТМО, токены Telegram и реальные параметры VLESS/Reality нельзя добавлять в Git.
